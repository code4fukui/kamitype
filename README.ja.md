# kamitype

C言語初心者が予約語や一般的なキーワードに慣れるのを助けるための、シンプルなターミナルベースのタイピングゲームです。C言語で作成されており、[liblove.c](liblove.c)のキーボード入力処理機能を使用しています。

## 遊び方

ゲームを開始するとC言語のキーワードが提示され、入力した文字が1文字ずつ判定されます。20単語を入力し終えると、成績（パフォーマンス統計）が表示されます。

```text
$ ./a.out
struct (1/20)
struct
volatile (2/20)
volatile
return (3/20)
return
...

-- 20単語入力後 --

time: 25 sec
speed: 132 type/min
ntype: 55
nmiss: 3
score: 129 point (speed - nmiss)
```

## 主な機能

- **キーワードの練習:** [words_c.h](words_c.h) のリストからランダムに選ばれた、予約語、型、プリプロセッサディレクティブなどのC言語のキーワードをタイピングします。
- **即時フィードバック:** 正しく入力された文字は画面に表示され、間違った入力をするとターミナルのビープ音が鳴ります。
- **明確な目標:** 20単語を正しく入力し終えるとゲームクリアとなります。
- **成績の表示:** プレイ終了時に、以下のパフォーマンスの概要が表示されます。
  - 経過時間（秒）
  - タイピング速度（1分あたりの入力文字数）
  - 正しく入力した総文字数
  - ミスタイプ数
  - 最終スコア（`speed - nmiss` で算出）

## 動作環境

- Cコンパイラ（GCC、Clangなど）
- POSIX準拠のターミナル環境（Linux、macOS、WSLなど）

## ビルドと実行

リポジトリをクローンし、以下のコマンドでコンパイルしてゲームを実行します。

```bash
# ソースファイルをコンパイル
gcc kamitype.c -o kamitype

# 実行ファイルを実行
./kamitype
```
